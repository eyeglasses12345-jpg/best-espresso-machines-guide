# Projects Folder

This folder stores project-specific affiliate authority site systems.

Each new project should get its own folder, for example:

/projects/best-espresso-machines-guide/
/projects/nugget-ice-makers/
/projects/pizza-ovens/

Each project folder should contain:

- CLIENT_PROFILE.md
- CATEGORY_SYSTEM.md
- PRODUCT_LIBRARY.md
- TAXONOMY.md
- BATCHES.md
- ASSETS.md
- /pages

Do not put global governance files directly inside this folder.
