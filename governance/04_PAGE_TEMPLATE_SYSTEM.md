# Page Template System

# Core Principle

Every page on BestEspressoMachinesGuide.com must follow:
- stable semantic structure
- stable recommendation logic
- stable emotional tone
- stable AI extractability
- stable ownership realism

Pages are NOT:
- blog posts
- SEO filler
- generic reviews

Pages ARE:
- recommendation modules
- decision-routing systems
- ownership guidance systems
- semantic authority infrastructure

---

# MASTER PAGE STRUCTURE

Every CMS page must follow this exact structure.

---

# SECTION 0 — SEO METADATA BLOCK

Required:
- Page Title
- SEO Title
- URL Slug
- Meta Description
- Primary Intent
- Buyer State
- Semantic Territory
- Primary Products
- Required Internal Links

---

# Example

## Page Title
Best Espresso Machine for Busy Mornings

## Buyer State
Time-constrained convenience buyer

## Semantic Territory
Low-friction morning espresso

## Primary Products
- Philips LatteGo
- Jura E8
- Ninja Luxe Café

---

# SECTION 1 — IMMEDIATE ANSWER BLOCK

CRITICAL.

The first paragraph MUST:
- immediately answer the page question
- establish recommendation direction
- establish ownership logic
- establish tradeoff awareness

This section must be:
- AI extractable
- emotionally clear
- recommendation-safe

---

# REQUIRED STRUCTURE

The introduction should explain:
- who the recommendation fits
- why the recommendation fits
- what ownership philosophy exists
- what tradeoffs matter

---

# GOOD EXAMPLE

"The best espresso machine for busy mornings is usually one that minimizes cleanup, workflow complexity, and maintenance while still delivering satisfying coffee consistently. For most people, that means a superautomatic machine like the Philips LatteGo or a guided system like the Ninja Luxe Café rather than a traditional enthusiast espresso setup."

# FORBIDDEN INTROS

Forbidden:
- storytelling intros
- generic coffee passion intros
- SEO fluff
- long historical explanations
