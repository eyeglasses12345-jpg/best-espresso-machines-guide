# COMPARISON PAGE GUARDRAILS

## Purpose

Comparison pages must be true side-by-side decision assets.

They must not read like generic ownership philosophy pages with two product names inserted.

A comparison page must help the buyer clearly understand:

- what each side actually is
- who each side is for
- who should avoid each side
- what changes in ownership
- what regret looks like on each side
- when to switch from one side to the other
- what page to read next based on the buyer’s remaining uncertainty

---

## Applies To

This guardrail applies to any page containing:

- `vs`
- `versus`
- `compare`
- `comparison`
- `alternative`
- direct product comparison
- direct machine-type comparison
- direct ownership-model comparison

Examples:

- Breville Bambino vs Bambino Plus
- Automatic vs Semi-Automatic Espresso Machine
- Built-In Grinder vs Separate Grinder
- DeLonghi vs Breville Espresso Machine
- Super-Automatic vs Semi-Automatic Espresso Machine

---

## Mandatory HTML Description Structure

Every comparison page must include these exact decision sections.
