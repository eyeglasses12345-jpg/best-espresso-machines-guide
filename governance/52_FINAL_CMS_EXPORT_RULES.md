# Final CMS Export Rules

# Purpose

This file defines:
# the mandatory export formatting rules for all CMS-ready production pages.

These rules ensure:
- consistent deployment
- clean WordPress imports
- semantic stability
- schema integrity
- internal-link consistency
- scalable Codex production

No page may export without following these rules.

---

# MASTER EXPORT RULE

Every exported page must be:
# immediately paste-ready for CMS deployment.

The VA or publisher should NOT need to:
- rewrite content
- restructure HTML
- repair schema
- fix formatting
- guess link placement

Every exported page MUST contain:

1. Metadata Block
2. HTML Description
3. HTML FAQ
4. HTML FAQ Schema

In EXACT order.
