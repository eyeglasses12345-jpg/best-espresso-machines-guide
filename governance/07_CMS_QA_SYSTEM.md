# CMS QA System

# Core QA Philosophy

Every page on BestEspressoMachinesGuide.com must pass:
# semantic validation.

This is NOT:
traditional proofreading only.

This IS:
- recommendation validation
- ownership realism validation
- semantic consistency validation
- AI clarity validation
- ecosystem integrity validation

The goal is NOT:
simply “publish content.”

The goal IS:
# deploy trustworthy recommendation infrastructure.

---

# MASTER QA RULE

A page is NOT complete because:
- it is long enough
- it is grammatically correct
- it contains affiliate links

A page is ONLY complete when:
# it strengthens the semantic recommendation ecosystem.

---

# QA VALIDATION LAYERS

Every page must pass ALL validation layers before publishing.
