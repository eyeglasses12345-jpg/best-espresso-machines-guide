# Internal Link System

# Purpose

This file defines:
# the semantic internal-link architecture for BestEspressoMachinesGuide.com.

Internal links are NOT:
random SEO links.

Internal links ARE:
# buyer-navigation infrastructure.

The internal-link system exists to:
- guide decision progression
- reinforce ownership clarity
- preserve semantic neighborhoods
- strengthen AI understanding
- reduce buyer confusion
- increase recommendation trust

---

# CORE INTERNAL LINK PRINCIPLE

Every internal link must answer:
# “What does the buyer need NEXT?”

NOT:
“What page can we force a link into?”

---

# PRIMARY INTERNAL LINK GOALS

Internal links exist to:
- narrow decisions
- clarify ownership styles
- explain tradeoffs
- reduce regret
- support progression
- reinforce semantic relationships

---

# FORBIDDEN INTERNAL LINK BEHAVIOR

NEVER:
- insert random SEO links
- overstuff links
- break emotional continuity
- force unrelated comparisons
- link solely for crawl depth
- inject irrelevant “best” pages

If a link weakens:
- buyer clarity
- emotional flow
- semantic purity

→ the link fails.
