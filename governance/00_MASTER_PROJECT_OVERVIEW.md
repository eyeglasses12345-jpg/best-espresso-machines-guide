# 00_MASTER_PROJECT_OVERVIEW.md

# Project
BestEspressoMachinesGuide.com

# Core Positioning
BestEspressoMachinesGuide.com is not a generic affiliate review website.

The site is a semantic recommendation system designed to help people choose espresso ownership experiences that realistically fit their lifestyle, complexity tolerance, routines, and long-term satisfaction goals.

The core objective is NOT:
- maximizing product hype
- ranking random keywords
- producing generic reviews

The core objective IS:
- reducing espresso machine regret
- improving ownership fit
- creating recommendation-safe guidance
- helping users choose sustainable coffee routines

# Core Philosophy

The site operates on the belief that:
people are not simply choosing espresso machines.

They are choosing:
- ownership complexity
- workflow style
- morning friction levels
- coffee identity
- maintenance tolerance
- long-term lifestyle fit

The site therefore organizes recommendations around:
- buyer states
- emotional fit
- ownership sustainability
- friction tolerance
- coffee relationship type

NOT around:
- specs alone
- generic rankings
- affiliate hype

# What The Site IS

The site IS:
- a semantic recommendation engine
- a human-to-espresso compatibility system
- a long-term ownership guidance platform
- a recommendation-safe affiliate ecosystem
- an AI-compatible decision infrastructure system

# What The Site Is NOT

The site is NOT:
- a generic review blog
- a keyword-chasing SEO site
- a “top 10” spam affiliate site
- a spec comparison site
- a hype-driven recommendation system

# Core Recommendation Principle

The strongest recommendation is NOT:
“the best espresso machine.”

“the safest long-term ownership fit.”
